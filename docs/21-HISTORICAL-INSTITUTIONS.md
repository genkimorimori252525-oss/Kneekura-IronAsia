# 国際連盟・国際連合：史実の制度的基線
調査日: 2026-11-14。史実とIronAsiaの反実仮想ルールを分けるための資料。これは**設計資料**であり実ゲーム検証ではない。

## まず区別すること
- 国際連盟と国際連合は別組織・別規約。1945年になったら強制的に改名してよい、という関係ではない。
- 国際連盟の理事会の全会一致原則と、国際連合の安保理における常任理事国拒否権は別制度である。
- 「常任席を増やす/廃止する」「席の代表政府が変わる」「既存国の地位を別の国が継続する」「非常任席を改選する」は別の手続である。
- 経済的先進国/列強/影響力ある国家と国連の常任理事国は別属性。国連に統一した先進国・途上国の公式定義はない。

## 国際連盟
- 1920年の当初の常任理事国は大英帝国、フランス、イタリア、日本。ドイツは1926年、ソ連は1934年に常任理事国へ追加された。
- 非常任理事国席は1920年4→1922年6→1926年9→1933年10→1936年11と増加。史実1936年開始時の実際の各国の加盟/理事資格は、脱退・発効時点を含めて個別照合する。
- 総会・理事会の実体判断は原則全会一致（例外と手続事項を除く）。単なる国連安保理の旧バージョンではない。
- 紛争の調査・仲裁、制裁の協調、軍縮、国際協力が役割。条文上の制裁と実際の履行は別。世界の国々が自動的に従うわけではない。
- 第16条の制裁をゲーム上で扱う際、各国の実施意思・協力能力・経済負担を表現する。連盟の常設独立軍を自動生成しない。

## 国際連合
- 1945年当初の安保理は11議席（常任5、非常任6）。常任席は米英仏ソ・中国。
- 1965年8月31日、1963年採択の憲章改正が発効。15議席（常任5、非常任10）に拡大し必要賛成票は7→9となった。
- 非常任理事国は原則2年任期。段階的に毎年約半数を改選。退任直後の連続再選は不可。地域的な公平性と平和への貢献などを考慮する。
- 手続事項と実質事項、紛争当事者の棄権に関する例外を区別する。議題すべてに無条件のP5拒否権を設定しない。
- 憲章第108条の制度改正には、総会3分の2の採択と、**すべての常任理事国を含む加盟国3分の2の批准**が必要。単なる軍事ランキングの変化で常任資格が移らない。
- 1971年の総会決議2758は中国代表権の変更。中国の席を増やしたわけではない。
- 1991年のソ連からロシアへの国連地位の継続は、別の常任席を新設したことではない。
- 安保理は制裁や一定の軍事措置を決定でき、総会の勧告と法的性質が異なる。執行は加盟国が担い、決議と履行を区別する。PKOの派遣も任務・当事者の同意・費用・兵力提供を伴う。

## 設計上の厳守
史実の国連安保理改革は高い政治的障壁を持つ。インド・ブラジル・日本・ドイツ等が大国化しても、常任資格が勝手に与えられるわけではない。改革が成立しないことにも歴史上の意味がある。
一方、史実と別の展開なら国際連盟の存続、改革、新秩序の創設、新たな世界機関の設立を検討できる。ただしその場合はIronAsia独自の反実仮想ルールと明記する。
