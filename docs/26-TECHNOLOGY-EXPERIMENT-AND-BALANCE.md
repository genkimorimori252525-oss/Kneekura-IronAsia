# 技術力システムの実証・テスト計画（設計v0.1 / 2026-11-14）
**状態: POC未実施 / 本MOD未実装。** [24 技術発展構造](24-TECHNOLOGICAL-CAPABILITY-REFOUNDATION.md) と [25 研究方針](25-RESEARCH-POLICY-AND-LONG-HORIZON.md)の受入条件。

## 評価指標（ゲーム上・バニラ比較）
- 国家ごとの「技術を知っている」「自国内で造れる」「軍が実際に使いこなせる」を別々に観察。
- 小国の基礎研究遅延、大国の先端研究の独占率、特定分野への専門化の実益、技術を学ぶ時期と対戦相手の装備の差。
- プレイヤー操作数（研究候補選択/設計画面を開いた回数）とゲーム上の満足できる判断点の数を区別。
- 国内生産可能性、セーブ容量、エラー数、月次tick時間、戦闘性能への重複ボーナスを追跡。
- **強い数値補正が存在しても、技術研究を進めた結果として見えること**。独立した魔法の攻防バフではない。

## 固定のモデル国家（シナリオ。歴史的数値を勝手に決めない）
- 先進工業・研究国: 広い研究能力を持ち、軍事専門性/運用は別に観察。
- 小さな工業国: 1〜2分野を戦略的重点化できる。
- 海のない小国: 航空/歩兵/工業を優先し、海軍知識や造船能力は別評価。
- 海運・造船重点国: 研究と建造力の差、艦船の完成までに必要な時間を測る。
- 主要工業を失った戦争被害国: 既知の技術は保ち、製造・修復能力が下がり、復興で戻る。
- 分裂して新たに成立した国: 人材/工場/設計図の分配を試験。

## 数式は先に固定しない
1. 「能力スコアの閾値」と「実際の研究解放」を意図的に別設計。
2. 経験による成長には逓減（高水準ほど改善が難しい）を設定する候補。
3. 自動研究の費用は本来のバニラ研究に対し公平に。最低研究枠の単純な一括補填/無制限grantは禁止。
4. 最適な研究速度・遅れ年数はシナリオごとの比較で決める。研究や技術の新たな数値は**仮置き**として明記する。
5. 失敗したら無理な代替を「同等」と呼ばない。UIと行動の変更点を示しユーザーが選べる案を比較。

## 実施準備と停止条件
- 対象HOI4バージョン、DLC、テクノロジーID一覧と含まれる特殊プロジェクトを固定。
- バニラ/旧エンジン/新POCで比較し、プレイヤー操作量も計測。
- 全国家×全技術×毎日の総当りは採用不可。イベント・月次・国家別バケット更新、キャッシュ、差分検出を優先。
- データ駆動の研究分類は**開発時**にJSON/CSVから生成可能。ただしゲームランタイムはPdx Scriptに変換・検証する。
- 検証できないtech ID、存在しないDLC機能、研究予約と実際の付与の混同を発見したら停止しPOCとして記録。
- **最初の縦切り**: 小国1、研究大国1、海のない国家1で「研究方針」「普及」「工業/装備への反映」「切替とセーブロード」の最小実験を行う。
