# 旧「にーくらエンジン」の思想を取り込むための受け皿

**重要**: 2026-11-11の時点で旧エンジンの原本ファイル/計画書の所在を確証できていない。GitHub内の別プロジェクト「KNEEKURA Code LAB」の同名のengineは、HOI4用旧エンジンだと確認されていないため取り違えない。

## ユーザーの2026-11-11の説明から確認できる思想
1. 領土問題は国家関係の悪化・改善と結びつき、多様な外交の動態を生む。
2. 歴史的な出来事と国家間関係をよりリアルに扱う。
3. 既存の古い構造を無理に保守せず、新しい一貫した構造をゼロから作る。
4. ただし、価値ある思想は継承する。旧設計の全機能/実装を無条件に移植しない。
5. IronAsiaにとって外交・領土エンジンは一部分。研究、陸海軍、地図、継続世界、UI/自動化を含む包括MOD。
6. 実装担当AIに自己改善の余地を与え、発見した欠陥やより良い案を提案させる。

## 原本を見つけたら行うこと
- GitHub repo/ファイル/commit または添付資料/保存先を特定し、変更せず記録。
- 思想・ゲーム上の要求・旧実装の振る舞い・偶発的な技術制約・失敗例を分離。
- 「旧思想の継承」「改善して採用」「非採用」「未確定」を根拠付きで判断。
- 新設計へ移すとき、旧技術の名前/コード/モジュール分割が再び設計を縛らないようにする。
- 独立した説明可能な世界状態に落とし込む。旧システムの存在を理由に機能を増やさない。
