# IronAsia — 構想と設計原則 (draft 2026-11-11)

> 手軽に、深く。世界は自ら動く。
>
> プレイヤーが行う単純作業を減らし、国家・国際社会が自律的に動く世界を増やす。

## 目的と対象
- HOI4で長期キャンペーンを楽しめる、WWIIから戦後・その先へ発展する動的世界。1936年からの歴史的整合性を重視し、歴史を固定の脚本にはしない。
- 手軽な大方針運用を既定値にし、興味のある分野だけ段階的に手動化できる。自動化は任意、撤回可能、部門・戦闘群ごとに独立。
- 小国を研究枠不足や大量の細分化で恒常的に不利にしない。大国との国力差は残しつつ、操作量に比例して不公平にならない。
- 従来の「にーくらエンジン」から領土紛争、外交悪化・改善などの問題意識を引き継ぐが、未確認の旧仕様やコードは移植しない。機能は必要性から再設計する。

## 設計価値の優先順位
1. **選択の意味**: 自動で十分に遊べ、手動化で戦略的な違いが出る。ただし操作しないことを罰しない。
2. **歴史的な因果**: 領土要求→対話/国際機関/制裁→緊張→危機/講和など、世界状態と説明可能な履歴の連鎖を重視。
3. **長期耐久性**: 終戦後も国家間の再編、技術発展、軍縮、改革が動き続ける。決して「1945年で停止」としない。
4. **最小限の労力**: 複雑なシステムほど通知集約・自動管理・説明可能性を組み込む。複雑さの追加だけを成果としない。
5. **性能と保存**: 大規模日次総当り、過剰なイベント、保存不能な仮想状態を避ける。セーブ・復元を機能要件にする。
6. **史実と遊びの両立**: 史料に基づく初期条件、反実仮想を可能にする動的規則、ユーザーが選択できる史実寄り/自由モード。
7. **創造性の余白**: 実装AIは既存計画の欠陥・重複・代案を提案できる。確認済み要件を無断削除せず、提案と検証記録を残す。

## 可変操作モード（構想、実装可否未検証）
- 研究: AUTO（国家方針/不足設備優先） / ASSIST（候補提案） / MANUAL。
- 陸軍: 戦域/軍集団・軍単位でAUTO / ASSIST / MANUALを別々に指定する構想。既存の戦闘計画機能が下限; 将軍の経験・技能をAI判断の質にどう反映できるかは要実証。
- 外交: 国家戦略を自動追従 / 重大案件のみ承認 / 全て手動。
- 海軍: 艦隊運用/研究系統/設計に自動化と任意の詳細化。DLC別の能力差を検証する。
- 一括の「全部AI」ボタンだけに依存させない。混合モードを第一級要件とする。

## 導入範囲についての未決事項
- ゲーム開始年代/ゲームバージョン/DLC対応/マルチプレイ/旧セーブ互換は未確定。現行バージョンでの実機検証後に固定。
- マップ全面再構成、現代組織、海軍研究改革は設計スコープに入れるが同時実装しない。
- 内部的な世界状況の複雑化を「UI操作数の増加」で解決しない。

## 「完成」の意味
- 研究/軍/外交の少なくとも一つずつの自動・手動の切り替えがゲーム上で観察・再現できる。
- 歴史的事件が根拠と履歴を伴って新しい危機に影響する。
- 低操作量でも小国を含むキャンペーンが成立し、長期のパフォーマンス・セーブ読み込みが守られる。
- 実現できない機能を実装済みと表現しない。
