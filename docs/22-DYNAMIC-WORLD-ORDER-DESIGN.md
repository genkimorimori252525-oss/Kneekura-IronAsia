# World Order：時代に応じて再編される国際機関
2026-11-14。**構想・受入条件**でありゲーム実装は未着手。[史実の制度基線](21-HISTORICAL-INSTITUTIONS.md)を先に読む。

## プレイヤー体験
「1945年になったから連盟が消えて国連が登場する」ではなく、**戦争、講和、加盟国の信頼と外交交渉から制度が誕生・改革される**。
- 1936年の連盟は史実に近い会員/条約状態から始まり、弱いことにも理由がある。
- 連盟が改革されて存続する世界、連盟が政治的に機能不全になり国連が誕生する世界、対抗する複数の機関が生まれる世界などを許容。
- 史実の連盟と国連は別ID・別規約。移行しても旧機関の加盟/決議の履歴は残る。
- 国際機関は領土紛争、仲裁、軍縮、停戦、制裁、人道支援、戦後復興、代表権、軍事介入の国際的な正統性に意味を持つ。
- 国家は決議に従うとは限らない。制度への協力度・加盟国の執行意思・費用負担・影響を描く。
- 既定は自動進行。プレイヤーは政策方針を選び、重大案件だけ提案・投票・批准・参加・拒否を操作できる。

## システム状態（概念モデル）
1. Organization: 組織ID、現行憲章、活動/機能不全/改革中/後継移行、正統性、実効性、予算と執行能力。
2. Membership: 加盟、申請、脱退、資格停止、分裂や併合に伴う資格処理。国家とその政府の代表権を区別。
3. Seats: 固有の議席ID、常任/非常任、任期、地域枠、代表国家。議席の存在と占有者を別管理。
4. Influence: 経済的発展度、相対的国力、外交的支持、地域代表性、軍事的貢献、評判。これらは提案/選挙の材料であって常任席の自動交換スコアではない。
5. Proposal: 案件ID、提案国、対象国、規約上の根拠、投票要件、投票者、拒否権と例外、期限、決定、執行担当、履行結果。
6. Chronicle: 成立した規約、当選/代表変更、重要な賛否と拒否権、不履行と制度の信用への影響を追跡。

これはデータ設計図であり、HOI4の変数/配列がこの形をそのまま持てるという保証ではない。保管の形はPOC後に確定。

## 4種類の理事国再編
**A. 非常任の定期選挙**
- 連盟と国連で任期・選挙方式と議席数を別に管理。
- 国連は2年任期・段階的改選、選出条件は地域的公平性と外交/国際貢献等。大国が常勝しない工夫。
- 空席、国家消滅、任期切れ、セーブからの再開にも耐える。

**B. 既存の席を代表する政府の変更**
- 1971年中国型の代表権変更。国家の地位/席の数は不変で、代表者・支持・履歴の更新に重点。
- 代表権争いは政治案件であり、単純な国力比較だけでは決定しない。

**C. 国家継続と承継**
- 1991年のソ連→ロシア型。国家の消滅/分裂と国連の既存資格の継続を区別し、外交承認や反対も経路にする。
- 失敗時に自動的な空席処理/後継者決定ができる安全策が必要。

**D. 条約・憲章の改革**
- 1965年の非常任議席増加に相当する制度改革。
- 常任理事国の追加/交代/拒否権変更は**提案→交渉→採択→批准→発効**の段階が必要。史実厳密設定では国連憲章108条のP5全員の批准を維持。
- 大国が改革を妨害した場合、政治危機、地域的制度の発展、脱退、別の秩序形成などが生じ得るが、すべてが必ず発生するわけではない。

## 年代を強制しない状態遷移
- LEAGUE_ACTIVE → LEAGUE_WEAKENED → LEAGUE_REFORMED / SUCCESSOR_NEGOTIATION / DEADLOCK
- SUCCESSOR_NEGOTIATION → UNITED_NATIONS / ALTERNATE_ORGANIZATION / FAILURE
- UNITED_NATIONS → NORMAL / REFORM_DEBATE / AMENDED / PARALYZED
史実モードでは史実の政治/戦争が起これば似た結果になるよう重み付けするが、**1945年になっただけで切替**しない。
非常任席の増加も加盟国数・地域要求・外交交渉・批准に結びつけ、1965年を無条件の実行日にはしない。

## 機関の権限と現実の効き目
- 紛争の調査/仲裁: 当事国の同意と制度的権限に応じて停戦・融和・緊張の変化。
- 制裁: 決議で対象と措置を決める→参加各国の協力に応じて効果が変わる→負担国の反発や迂回も記録。
- 停戦監視/PKO: 適用年代と制度上の権限、国家による兵力/費用提供と当事国同意を重視。国連決議から無料の無限兵力を召喚しない。
- 武力措置: 憲章・安保理の条件と加盟国の参加を必要とし、単なる全会一致の自動開戦にはしない。
- 途上国支援/経済再建/疾病対策などの非軍事的役割は、時代に合う組織の実際の機能を別途調査して拡張。
- 機能不全/拒否権による不成立を正当な結果として扱う。機関の強化とは、必ず可決できる万能化ではない。

## ゲーム操作は少なく
- AUTO: 定期選挙、軽微な勧告、日常外交は方針に沿って自動。重要案件のみダイジェスト通知。
- ASSIST: 自国に重大な影響がある制裁・軍事派遣・憲章改正案は提案と説明を表示。
- MANUAL: 対象分野だけプレイヤーが直接投票・発議・批准を決める。
- 重要でない国家に、全国家の全投票UIを見せない。
- 選べるルール: 史実厳密 / 史実らしい反実仮想（推奨） / 改革されやすい自由世界。史実規約を変える場合はゲーム上でも明示。

## 安全・性能
- 重要事件時更新と月次/年次評価を優先。全加盟国×全国家の毎日評価は避ける。
- 提案キュー、採決、終結を状態機械で管理し、対象国消滅/代表交代/離脱中は投票を中止または再評価。古い投票結果・拒否権・ロックを確実に解放する。
- 出典と旧エンジンの設計思想は [旧設計移行](62-LEGACY-TO-IRONASIA-MIGRATION.md)、類似MODの国連実装は [ケーススタディ](11-IMPLEMENTATION-CASE-STUDIES.md)。
- 関係史と議決履歴はセーブ可能範囲で保存。外部JSON書き出しは別途セーブ解析ツールが必要な可能性が高い。

## 実装前のPOC
1. 1936連盟下、2国国境問題＋第三国仲裁の採決から履行/不履行まで検証。
2. 国連型非常任選挙の任期/当選/地域配分/欠員補充を再現。
3. 代表政府変更時に常任議席を増やさず状態を引継げることを確認。
4. 新常任議席の改革が、現存常任国1か国の反対で失敗することを確認。
5. 世界大戦不発の年表で1945年に国連へ強制切替しないことを確認。
6. 採決中の併合/分裂/代表権交代でハングしないことを確認。
7. 自動/手動の切替と、セーブロード後の議席/決議状態の一致を確認。
8. バニラ比較でゲーム速度、セーブサイズ、error.logを計測する。
